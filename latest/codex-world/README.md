# CODEXWorld（COW）

COWは、干場の助言を版付き規則としてブラウザ内に保存し、単一HTMLアプリを企画・生成・検証・承認するCG無料運用アプリです。ClaudeWorldの略称はCLWです。

## 運用

1. 「作る」で、作ってほしいアプリを一文だけ指示する。
2. COWが名称・ジャンル・中心機能を決め、企画・HTML生成・自己検証・修復を連続実行する。
3. 干場は「プレイ・レビュー」で完成候補を操作する。
4. 修正があれば一文レビューを渡し、COWが規則として学習して再完成させる。
5. 問題がなければCG掲載を承認する。成果物は同一ブラウザのCG「COW成果物」とCOW書庫へ掲載される。
6. 「書庫」でジャンル別フォルダを確認し、HTML単体、フォルダZIP、全書庫ZIPを出力する。
7. 公開CGへ恒久掲載するときはZIP内の `catalog.json` と各フォルダを次回の静的サイト更新へ取り込む。

## 無料・安全境界

- 実行時にCodexや外部AI APIを呼ばない。通信なしでテンプレート生成する。
- CODEXWorld本体の自己書換えは行わない。
- 生成物の確定、ファイル出力、公開は承認後だけにする。
- 状態は `cow-state-v1`、CG表示用成果物は `cg-cow-artifacts-v1` に保存する。
- ブラウザ容量を守るため、成果物と履歴には保持上限を設ける。
