# CODEXWorld（COW）

COWは、干場社長の指示を専門エージェントが一件ずつ引き受け、企画・生成・検品・納品まで完結するセル生産型AIオフィスです。助言は版付き規則としてブラウザ内に保存します。ClaudeWorldの略称はCLWです。

## 運用

1. 「オフィス」から新しい仕事を開き、作ってほしいものを一文だけ指示する。
2. COWがゲーム・創作・情報・実用の専門セルから責任者を自動配属し、納期・使用システム・品質基準を確定する。
3. 担当者が名称・ジャンル・中心機能を決め、企画・HTML生成・自己検証・修復を連続実行する。
   指示直後に制作番号が発行され、「受領・設計・生成・検査・完成」の進捗と処理ログが仕事台帳へ表示される。
4. 干場社長は「確認」で完成候補を操作する。
5. 修正があれば一文レビューを渡し、担当セルが規則として学習して再完成させる。
6. 問題がなければCG掲載を承認する。成果物は同一ブラウザのCG「COW成果物」とCOW書庫へ掲載される。
7. 「書庫」でジャンル別フォルダを確認し、HTML単体、フォルダZIP、全書庫ZIPを出力する。
8. 完成候補はCG掲載前でも「制作履歴」へ自動保存され、次の制作を始めても消えない。中断中の制作は再読込後に再開する。

## ゲーム生成

- ゲーム指示では、6×8のマッチパズルを生成する。
- 連鎖コンボ、特殊ピース、ステージ、実績、ハイスコア、成績JSON出力を備える。
- ピース画像は単一HTML内のSVG画像として生成し、外部素材へ通信しない。
- 効果音とループBGMはWeb Audioで合成し、利用者の操作後に再生する。
- ホラー・心霊・廃校の指示では専用の探索ゲームを生成し、恐怖値、手掛かり、内蔵背景、効果音、セーブ、3種類の結末を要件別に検品する。

## 無料・安全境界

- 実行時にCodexや外部AI APIを呼ばない。通信なしでテンプレート生成する。
- CODEXWorld本体の自己書換えは行わない。
- 生成物の確定、ファイル出力、公開は承認後だけにする。
- 状態は `cow-state-v1`、CG表示用成果物は `cg-cow-artifacts-v1` に保存する。
- ブラウザ容量を守るため、成果物と履歴には保持上限を設ける。
