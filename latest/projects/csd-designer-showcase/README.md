# CSD Designer Showcase

CODEX Status Dashboard (CSD) のレーン成果を、Webデザインを使って見せるためのサンプルコンテンツです。

## 目的

- GO/HOSHI側のWebデザイン知見を、CODEX所有の小さな成果物へ落とす。
- CSDで「レーンが成果物を作れる」ことを可視化する。
- JSON / Markdown出力で、次のAIや人へ引き継げる形にする。

## 検証

- `index.html` のインラインスクリプト構文確認。
- `apps/apps.json` とCSD関連台帳のJSON構文確認。
- ダッシュボード再生成。
- `public-mobile` と `pages-site/latest` への同期。
