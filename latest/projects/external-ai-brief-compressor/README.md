# 外部AIブリーフ圧縮器

スマホから外部AIへ渡す依頼を、短く選択式で作るCG掲載コンテンツです。

## 機能

- 目的、対象、出力形式、トーン、確認観点を選択
- MV、音楽、歌詞、画像、イラスト、ゲーム、アプリ、Web記事、調査の専用レーンを選択
- 少ない入力で外部AI向けブリーフを生成
- チャット欄へのコピー、外部AI/Web依頼、CODEXタスクリスト保存の出力先を選択
- 曖昧さ、GO判定、超概算トークン量を表示
- セット完了、GOサイン、タスクリスト可視化
- 進行ボードでセット、仕掛、完成の件数とカードを可視化
- 保存タスクをセット、仕掛、完成へ移動
- 保存タスクの再開、個別コピー、個別削除
- コピー、JSON書き出し、Markdown書き出し
- ブラウザ内保存

## 状態

CGのエコレーン向け単一HTMLアプリです。
